GTA III - Definitive Edition

About

Grand Theft Auto III – Definitive Edition is the remastered version of the classic 2001 title included in Grand Theft Auto: The Trilogy – The Definitive Edition. It features improved lighting, higher-resolution textures, updated controls, and quality-of-life enhancements while preserving the original story set in Liberty City.

Game Information

Developer Grove Street Games / Rockstar Games
Publisher Rockstar Games
Release 2021
Main Character Claude
Location Liberty City
Engine Unreal Engine

New Features

  • HD textures
  • Improved lighting
  • Enhanced reflections
  • Updated controls similar to GTA V
  • Higher draw distance
  • Improved checkpoints
  • Modern weapon wheel
  • Achievement support
